# ViveYaTravel ✈️

¡Bienvenido a **ViveYaTravel**! Este es un proyecto universitario en donde se realizo un aplicativo web diseñado para una agencia de viajes, donde los usuarios pueden registrarse, iniciar sesión y explorar una amplia variedad de paquetes turísticos de forma interactiva.

---

## 🚀 Características Principales

* **Autenticación de Usuarios:** Registro e inicio de sesión seguro para los clientes.
* **Sincronización en Tiempo Real:** Actualizaciones inmediatas en la visualización de los paquetes de viajes.
* **Notificaciones por Correo:** Integración para el envío de confirmaciones y alertas a los usuarios.

---

## 🛠️ Tecnologías Utilizadas

El proyecto está desarrollado bajo la arquitectura **MVC (Modelo-Vista-Controlador)** y utiliza el siguiente stack tecnológico:

* **Backend:** Java 21 & JSP (JavaServer Pages)
* **Frontend:** JavaScript, CSS3 & HTML5
* **Base de Datos:** MySQL
* **Servicios externos:** JavaMail API (para el envío de correos electrónicos)

---

## 📋 Requisitos Previos

Si deseas ejecutar este proyecto de manera local, asegúrate de tener instalado:

* **Java Development Kit (JDK):** Versión 21.
* **Servidor de Aplicaciones:** Apache Tomcat (o compatible con Jakarta/Java EE).
* **Gestor de Base de Datos:** MySQL Server.
* **IDE recomendado:** IntelliJ IDEA, Eclipse o NetBeans.

> 🌐 **Despliegue en producción:** https://aplicacionagenciadeviajes-production.up.railway.app/
